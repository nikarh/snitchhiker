Snitchhiker’s eBPF programs, embedded in the binary, and their loader.

The programs (in bpf/, GPL-2.0-only OR MIT) record, for every new TCP connection and UDP flow, which process opened it, keyed by the flow; Attribution::owner looks a queued packet’s flow up. The hooks run before the flow’s first packet leaves, so its owner is known by the time the packet is queued.
