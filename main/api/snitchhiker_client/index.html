Source
Expand description

A blocking client of a Snitchhiker node over its local sockets: the handshake, requests (answered by id) and subscription notices (queued while a request waits for its answer).

Before saying anything, a client checks it is talking to the node: the socket is in a directory only root can change, and the process serving it runs as root. A process that bound a socket somewhere else, or got one into a directory it may write, can’t pose as the node to answer the client’s requests or feed it prompts.
