Snitchhiker’s client protocol: the generated messages (proto/snitchhiker/v1/*.proto is the source of truth), framing, the local preamble, and conversions to and from the core model.

Re-exports§

pub use prost;

Modules§

columns
Columnar blocks: bulk data (event pages, live event batches) as columns of fixed-width little-endian values, read in place from the received buffer.
convert
Between the wire messages and the core model. Rules travel in the shape of rule files (spec), so a rule a client sends is checked exactly like a rule in a file.
frame
Frames: a little-endian u32 length and a protobuf message; and the local connection’s preamble.
system
The system firewall between the core model and the protocol: what clients are sent, and what they send, checked.
v1
The generated messages of major version 1.
