snitchhiker_remote

Module code 

Source
Expand description

Pairing codes (decision 0010): <nameplate>-<word>-<word>-<word>, to type where a link can’t be pasted or scanned.

The nameplate (1 to 999) names a meeting point: an endpoint whose key is derived from it, which anyone can derive too. The node waits there, on the LAN (mDNS) and on its relays, for one attempt. Both sides run SPAKE2 with the whole code as the password: only someone who knows the words derives the same key, and an attacker at the meeting point (or on the relay) gets one online guess, against 2048³ words, after which the code is spent. The device proves it derived the key first; only then does the node send its pairing link, sealed with it. The device then pairs as a link does, with the real node’s key proven by TLS.
