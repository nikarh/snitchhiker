Snitchhiker’s remote transport (plan §8.2): the client protocol over iroh, QUIC between Ed25519 keys, direct where a path is found (hole punching, port mapping) and through the user’s own relays otherwise.

The node and the clients speak the protocol on blocking sockets and threads; iroh is async. Each QUIC stream is therefore bridged to one end of a Unix socket pair by a task on a small tokio runtime of its own, and the other end is what the protocol code reads and writes: a remote connection is served exactly like a local one.
