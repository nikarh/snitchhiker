snitchhiker-relay: the relay a user’s nodes and devices meet through when no direct path exists (plan §8.4). It is iroh’s relay server, configured from a TOML file: TLS by ACME, by certificate files, or none behind a reverse proxy that terminates it; optionally only listed endpoint ids may use it. Traffic through it stays end-to-end encrypted between node and device: the relay sees endpoint ids and opaque packets.
