Module netlink 

Source
Expand description

Netlink messages for the netfilter subsystems: a writer that builds them into a reused buffer, a parser that reads them in place, and a socket that sends a batch and collects the kernel’s answers.

Nothing here allocates once the buffers have grown to their working size.
