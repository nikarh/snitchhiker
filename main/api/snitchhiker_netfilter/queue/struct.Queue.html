impl Queue

Source

pub fn bind(number: u16) -> Result<Self>

Binds queue number. When the queue is full the kernel drops new packets: overflow never lets traffic through (NFQA_CFG_F_FAIL_OPEN is explicitly cleared), so flooding the queue cannot open the firewall.

Source

pub fn bind_copying(number: u16, copy_range: u32) -> Result<Self>

Like Queue::bind, copying up to copy_range bytes of each packet (for queues that read payloads).

pub fn receive(&mut self) -> Result<impl Iterator<Item = Packet<'_>>>

Blocks until the kernel sends packets, and returns them (often one, sometimes a burst).

Source

pub fn verdict_writer(&self) -> Result<VerdictWriter>

A handle that decides this queue’s packets from another thread (packets held for a prompt). The kernel takes verdicts only from the socket the queue is bound to; the handle writes to a duplicate of its descriptor, which is the same socket.
