Module query

The query language: one small language for rule search, event filters, Explorer pivots and alert conditions.

exe:*/curl host:*.example.com -port:443
(action:deny OR action:reject) time>-1h bytes>10M
firefox user:1000

Terms are key:value (or key>value, key>=value, key<value, key<=value for numbers and times), joined by whitespace (and) or OR, negated with a leading -, grouped with parentheses; a value can be quoted. A bare word is free text. A value with * or ? is a glob over the whole value; without, it matches anywhere in it. Text matches ignore case.

parse gives the syntax tree, with each term’s place in the text so a client can highlight it (tokens gives the classified tokens for that). EventFilter::compile checks it against the event keys; the filter then runs in memory (EventFilter::matches) or as SQL (EventFilter::sql), whose matching functions call back into the same code (glob, text, in_net) so both always agree. RuleFilter does the same for rules, in memory only (clients hold every rule).
