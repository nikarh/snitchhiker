Expand description

The suggestions for a connection from a container, a VM or another network namespace: the same rules, made to hold in that context only (a rule made from a container’s prompt never applies to the host), and for a container, its own ladder after the first (plan §5.10): any program in it, any container from its image, this exact container.

A container is named by its most stable identity: its Compose service, else its name, else its image.
