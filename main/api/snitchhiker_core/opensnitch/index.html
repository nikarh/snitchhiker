Module opensnitch

Expand description

Importing OpenSnitch’s rules (/etc/opensnitchd/rules/*.json, its documented format) as a rule file.

Each rule converts to one that matches exactly what OpenSnitch’s matched, or is reported with the reason it can’t:

  • simple operators compare whole values, case-insensitively unless sensitive; regexp ones match anywhere in the value (Go’s MatchString); network ones match a CIDR range; list ones need all of theirs to hold, as Snitchhiker’s conditions do.
  • Host names compare without case in Snitchhiker anyway. Other case-insensitive values become (?i) regular expressions; unanchored regular expressions are wrapped so they still match anywhere.
  • precedence rules go in the override tier; others in the normal one.
  • Temporary rules (any duration but always) are left out: they were never meant to last.
  • Operands Snitchhiker has no condition for (environment variables, interfaces, process ids, hashes, block lists) are reported, not approximated.

OpenSnitch can’t tell containers apart, so its rules matched their processes too. Imported rules apply to the host only, as every Snitchhiker rule without a context condition does; the report says so.
