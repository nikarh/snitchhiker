Source
Expand description

Shaping agents’ proposals (plan §5.11). An agent only suggests: what reaches a person is a rule made from what the kernel saw where it can be (the program of the blocked connections, not the one the agent typed), refused when it would allow every program everywhere, and marked wherever it is broad, so that approving it needs a second look (and step-up).
