Module system 

Source
Expand description

The system firewall: the base packet filter the node keeps beside its application rules (inbound and forward policies, and rules over protocols, addresses, ports, interfaces and connection state), as a form over a fixed set of statements rather than raw nftables text.

The defaults are those OpenSnitch ships (written from the list of what they do): ICMP echo and unreachable messages allowed; SSH inbound, loopback, a WireGuard exclusion and queueing forwarded connections present but off.
