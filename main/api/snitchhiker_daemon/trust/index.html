Module trust 

Source
Expand description

The trusted-client registry: the client binaries root registered with snitchhikerd trust-client, each pinned to its SHA-256.

It is a file next to the database (trusted-clients.toml), so packages can register their client from an install hook whether or not the daemon runs. The daemon reads it whenever a client connects: a change applies to the next connection, with nothing to reload. The paths in trusted_clients of daemon.toml are trusted too, by path alone.
