Module push 

Source
Expand description

The node’s push gateway (plan §8.5): a snitchhiker-relay with its push service on, which wakes devices that are asleep when a prompt waits for them, and tells them when the node goes offline. The node keeps one stream open to it (ALPN snitchhiker-push/1) for as long as it runs: the stream ending is how the gateway knows the node is gone, exactly, with no heartbeats to count. On it the node says who to tell (each device’s push target, again on each change), who to wake, and why it stops, when it does.

The gateway learns the devices’ push targets and when the node needs them. It learns nothing about prompts, connections or rules: a wake-up says only “connect”.
