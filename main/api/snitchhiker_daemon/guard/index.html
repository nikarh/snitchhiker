Module guard 

Source
Expand description

What a change to the rules, folders, policy or system firewall loosens, judged on the state it leaves rather than on the request: any path to the same state (a rule added narrow and its folder’s scope removed after, a rule imported disabled and enabled after, a change undone) is the same dangerous action.

A change loosens when, after it:

  • an enabled rule, in enabled folders, allows broadly with its folders’ scopes ([allows_broadly]) that didn’t;
  • more than TURNED_OFF rules that were in force aren’t (deleted, disabled, or in a disabled folder);
  • the policy lets through what it blocked, or keeps less history;
  • the system firewall lets in what it kept out.
