Agents (decision 0008): who an agent is, what its own processes were refused, and its proposals.

An agent is the process that started the MCP server on the agent socket; its tree is it and everything it started, each process held by pid and start time. The node remembers, in memory, the lineage of every connection it didn’t allow over the last hour, so it can tell an agent what its own processes were refused, and nothing else.
