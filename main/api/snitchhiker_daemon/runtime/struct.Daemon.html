impl Daemon

Source

pub fn start(config: Config) -> Result<Arc<Self>, Error>

Opens the store, compiles the rules, installs the table, loads the attribution programs and starts the deciding threads and the writer.

Source

pub fn publish_proposal(&self, proposal: &Proposal)

Announces a proposal made or changed: to subscribers, and to requests waiting for a change.

Source

pub fn wait_for_proposals(&self, timeout: Duration, still: impl FnMut() -> bool)

Waits until still says no, checking it again whenever a proposal changes, for at most timeout.

Source

pub fn watch_agents(&self, agents: impl IntoIterator<Item = ProcessRef>)

Watches agents too: their session rules and waiting proposals end with them (at once, for those already gone).

Source

pub fn raise(&self, alert: &NewAlert)

Raises an alert from the API’s side.

Source

pub fn alert_rules_changed(&self)

The alert rules changed: the writer loads them again.

Source

pub fn version(&self) -> &'static str

The daemon’s version, with the suffix of development builds.

Source

pub fn store(&self) -> Guard<'_>

The store, for the API’s reads and writes.

Source

pub fn connections(&self) -> Result<Vec<LiveConnection>>

The live TCP connections and connected UDP sockets, each with its program as the attribution programs recorded it when it opened (unknown for inbound sockets, and for ones older than the daemon).

Source

pub fn explain(&self, seq: i64) -> Result<Option<Explanation>, Error>

Why the recorded connection seq is decided as it is, by today’s rules; None if there is no such event.

Source

pub fn kill(&self, id: &SocketId) -> Result<()>

Closes a live socket (as reject does): its program’s next call fails with ECONNABORTED.

Source

pub fn answer_prompt( &self, id: u64, action: Action, duration: Duration, suggestion: usize, conditions: Option<&Conditions>, folder: Option<FolderId>, by: &str, ) -> Result<Option<RuleId>, AnswerError>

Answers a prompt: makes a rule of the chosen suggestion (or conditions) unless duration is once, then decides every connection waiting on it. Returns the rule made, if any.

Source

pub fn apply_system(&self) -> Result<(), Error>

Reads the rules again and swaps them in. Makes the kernel’s system table what the store says.

Source

pub fn set_system( self: &Arc<Self>, firewall: &Firewall, app: &str, revert_after: Option<Duration>, ) -> Result<u64, Error>

Replaces the system firewall with firewall (checked), recording it as app’s change. With revert_after, the previous one comes back then unless Daemon::confirm_system is called first.

Source

pub fn confirm_system(&self) -> bool

Confirms the change on trial; false when none waits.

Source

pub fn system_reverts_at(&self) -> u64

When the change on trial reverts (Unix ms); 0 for none.

Source

pub fn reload_policy(&self) -> Result<Effective, Error>

Applies the policy as the store has it (after a client changed it, or an undo).

Source

pub fn reload_rules(&self) -> Result<usize, Error>

Source

pub fn stop(&self)

Stops: with fail = open the table is removed, so traffic flows freely; with fail = closed it stays, so nothing new gets out until the daemon is back.
