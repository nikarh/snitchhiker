Module router 

Source
Expand description

Prompt routing (plan §5.5): which clients are notified of a prompt. Every admin client lists every prompt and can answer it; routing only says who is to be told.

  • all: every client, but devices muted.
  • escalate: the clients on this machine first. Remote devices are notified when no client here listens, when the local users’ sessions are all locked or idle (logind says so), or once the prompt has waited escalate_after_secs. The decision is made on a thread of its own, never on the packet path: asking logind takes a D-Bus round trip.

A device to notify that isn’t connected is woken through the push gateway (Push), and told of the prompt when it connects.
