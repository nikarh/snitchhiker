Subscriptions: which connection wants which topic, and pushing notices to them.

Every connection has an outbox: a bounded queue its writer thread drains, and the strings the connection has been sent. A slow client’s queue fills up and it misses notices rather than slowing the node down; the next notice it gets says so (missed), so it can resume.

Columnar blocks refer to strings by id. The dictionary entries a frame carries are decided at the moment it is queued, under the outbox’s lock: an entry is in the first frame queued that needs it, so no frame can arrive using an id the client hasn’t been told yet, however responses and notices interleave.
