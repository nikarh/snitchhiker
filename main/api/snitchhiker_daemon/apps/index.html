Module apps 

Source
Expand description

Stable identities of programs (process.app): names that survive updates and moves, from facts only root (or the package manager, Nix or snapd) can set:

  • pkg:<name>: the package that installed the executable (pacman, dpkg, rpm databases);
  • nix:<name>: a program in the Nix store (/nix/store/<hash>-<name>-<version>/…);
  • unit:<name>.service: a system service (its cgroup, set by systemd; a user’s own units can be named anything, so they give none);
  • snap:<name>: a snap (its cgroup, set by snapd).

Flatpak and AppImage markers (.flatpak-info, APPIMAGE, a FUSE mount) can be made by any user in a namespace of their own, so they name nothing here (decision 0014). Identities are for programs on the host: inside a container, a path names something else.

The package index (executables only) is read when the daemon starts and again when a package database changes; looking a program up is a hash lookup.
