Source
Expand description

Paired devices over the network (plan §8.2, §8.3): the node’s iroh endpoint, pairing with one-time secrets, and the devices’ connections, served as local ones are and closed when a device is unpaired.

A device is its key: TLS proves the peer holds the key it connects with, and only keys paired with the node are served. Pairing hands the node the device’s key: the device connects on the pairing ALPN and sends a one-time secret it got from a link or a QR code (single use, 10 minutes, compared in constant time).
