Expand description

Prompts: connections no rule decides, held until a client answers or the prompt times out.

Connections of the same program and user to the same destination, port and protocol join one prompt: one question for a burst of connections, and for the retransmissions of a held SYN. Different prompts are independent: there is no “already asking” lock that makes every other connection get a default.
