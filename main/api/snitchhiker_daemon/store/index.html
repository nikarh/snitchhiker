snitchhiker_daemon

Module store 

Source
Expand description

The daemon’s state: rules, folders and the connection history, in one SQLite database.

Every statement the daemon runs is in STATEMENTS; a test runs EXPLAIN QUERY PLAN on each against a populated database and fails on a table scan or a temporary sort, so every query stays an index seek. Strings that repeat (executables, hosts) are stored once and referred to by id.
