snitchhiker-mobile: the Rust core of the Android app (decision 0011). It holds the app’s connections to its nodes (iroh, as the desktop app’s remote ones) and pairs with nodes; requests and notices cross as the protocol’s own messages, encoded. This file is only the JNI glue of core: the static methods of the app’s dev.nikarh.snitchhiker.app.Native. Errors and panics become Java RuntimeExceptions.

Modules§

core
The app’s core, in plain Rust (the JNI layer in lib.rs only converts): keys, pairing, and connections to nodes held by number. Requests and notices cross as the protocol’s own messages, encoded: the app decodes them with classes generated from the same schema, so every request the protocol has is the app’s too.
