Changelog

Every release, newest first. Each version links to its GitHub release, which has the files and the authors of each change. This page is generated from CHANGELOG.md, which git-cliff writes from the commits when a release is made.

0.1.02026-11-15

Features

  • netfilter: Manage the nf_tables table over netlink, without libnftables
  • netfilter: Hold queued packets and decide them, without allocating per packet
  • netfilter: Read a queued packet's addresses, protocol and ports in place
  • ebpf: Attribute new connections to their processes
  • daemon: Identify local clients from kernel facts, and admit only registered setgid binaries
  • core: Add the rule model and the engine that decides connections
  • daemon: Read the facts rules need about a connection's process
  • daemon: Store rules, folders and connection history in SQLite
  • daemon: Run the firewall: decide every new connection by the rules, and record it
  • netfilter: Copy DNS answers to an observing queue, and expose UDP payloads
  • daemon: Learn the names of addresses from DNS answers, so rules can name hosts
  • netfilter: Close a local socket by its addresses (sock_diag SOCK_DESTROY)
  • daemon: Make rejected connections fail at once
  • daemon: Tell systemd when the table is in place (Type=notify)
  • core: Add the rule file format people write, export and provision
  • daemon: Add the built-in System folder and root's managed rule files
  • ebpf: Count the bytes each socket sends and its program reads
  • daemon: Record how many bytes each connection moved
  • core: Generalise executable paths so rules survive updates
  • cli: Learn rules from what monitor mode saw, and import and export rule files
  • proto: Define the client protocol (version 1), its framing and its conversions
  • netfilter: Decide a queue's packets from another thread
  • core: Suggest the rules a prompt offers, narrowest first
  • client: Add a blocking client of the node's local sockets
  • daemon: Ask about connections no rule decides, over an authenticated local API
  • client: Refuse a socket that isn't the node's
  • daemon: Register trusted clients pinned to their digest
  • daemon: End a client's connection when its process exits
  • daemon: Require polkit step-up for allow-everything rules, and audit them
  • daemon: Resume subscriptions after a reconnect, and publish events
  • core: Suggest the address and its network in prompts
  • daemon: File rules made from prompts in the program's folder
  • proto: Add columnar event blocks
  • daemon: Send event pages and live batches as columnar blocks
  • proto: Add the columnar messages to the schema
  • ui: Add the desktop app

Fixes

  • proto: Prefix the error codes with their enum's name
  • daemon: Take a connection's user from the kernel's record of the socket
  • cli: Name the 12-hour prompt duration 12h
  • daemon: Create the database and other files readable by root only

Performance

  • daemon: Identify a connection's process by the kernel's record, without reading /proc per packet
