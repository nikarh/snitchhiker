Quick start

The packages start the daemon in monitor mode: nothing is blocked, and every connection is recorded with the decision that would have been made. A few days of that, then rules made from what was seen, then enforcing, is the safe way onto a machine you depend on. On a server, Servers goes through the same with rule files provisioned by your configuration management and a phone to answer.

4. Enforce

Section titled “4. Enforce”

In /etc/snitchhiker/daemon.toml, set the mode and what happens to connections no rule decides:

From now on a connection no rule allows is dropped. snitchhiker events shows what was blocked and why. To be asked instead, use no_match = "ask": see Prompts.

Caution

On a machine you reach over the network, allow your way in and out (SSH, the package mirrors) before enforcing. A stopped daemon never cuts the machine off: its tables go with it.
