### `get_status`

Whether the firewall is enforcing, and what happens to connections no rule decides. Call it when network commands fail in ways that could be the firewall.

No arguments.

### `check_connection`

How a connection would be decided now (allow, deny, reject, or ask a person), and by which rule. Changes nothing.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `exe` | string | yes | The program's full path. |
| `host` | string | yes | A host name or an address. |
| `port` | integer | yes | The destination port. |
| `protocol` | string | no | tcp by default. |

### `recent_blocked`

The connections of this session's own processes (the agent and the commands it ran) that the firewall refused or is asking a person about, over the last hour: program, host, port, count. Nothing of other processes. Call it first when a network command fails.

No arguments.

### `propose_rules`

Propose rules that allow connections, for a person to approve. Propose only what recent_blocked shows was refused and the task needs, as narrow as possible: the exact program, exact host names, the port. Good: `{exe: /usr/bin/cargo, hosts: [index.crates.io, static.crates.io], ports: [443]}`. Bad: any program, any host, `*.com`, a `/8` network, the LAN or `169.254.169.254`: those are refused or marked, and marked rules need the person's password. Approved rules apply to this session's processes only, and end with it, unless the person chooses longer. The justification is shown to the person as your words: one or two plain sentences on why the task needs it.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `justification` | string | yes | Why the task needs these connections. |
| `rules` | list of rules (below) | yes |  |

Each rule:

| Field | Type | Meaning |
| --- | --- | --- |
| `context` | string | Where the program runs; host by default. |
| `exe` | string | The program's full path, as recent_blocked shows it (e.g. /usr/bin/cargo). The node uses the program it saw refused, whatever is written here. |
| `hosts` | array | Exact host names (crates.io), `*.` and a name for its subdomains (*.githubusercontent.com), addresses or networks. Never empty: a rule for anywhere is refused or marked. |
| `ports` | array | Ports or ranges (443, 8000-8080). |
| `protocol` | string |  |
